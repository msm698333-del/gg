# سایهٔ خندان — بازی آنلاین چندنفره (۲ و ۳ نفره)

نسخه‌ی چندنفره‌ی بازی ترسناک «سایهٔ خندان» — ساخته‌ی کامل با Node.js، Express و Socket.IO.
جایگزین بازی «نقشه مهاجران» روی همان آدرس Render است.

## حالت‌های بازی

| حالت | بازیکنان | توضیح |
|---|---|---|
| انفرادی | ۱ نفر | فرزاد هوش مصنوعی است، دیان (AI) همراه شما فرار می‌کند |
| دو نفره | ۲ نفر | بازیکن ۱: فردین (فراری‌دهنده) | بازیکن ۲: فرزاد (شکارچی) |
| سه نفره | ۳ نفر | بازیکن ۱: فردین | بازیکن ۲: دیان | بازیکن ۳: فرزاد |

### قوانین بازی
- با جمع کردن **۴ کلید** به **در خروج** برسید (فرار کنید) — قبل از هر کلید، «صدای تاریکی» یک سؤال از شما می‌پرسد. پاسخ اشتباه = فرزاد عصبانی می‌شود و سریع‌تر می‌دود.
- اگر فرزاد (بازیکن) هر کدام از فراری‌دهنده‌ها (فردین یا دیان) را لمس کند، بازی تمام است.
- دیان علاوه بر چراغ‌قوه، یک **فلش خیره‌کننده** دارد که فرزاد را برای ۳.۵ ثانیه متوقف می‌کند (۱۵ ثانیه cooldown).
- فرزاد دائماً محیط را می‌بیند؛ فراری‌دهنده‌ها تاریک هستند و فقط با چراغ‌قوه جایی را می‌بینند.

## کنترل‌ها

- حرکت: کلیدهای WASD یا جهت‌دار / روی موبایل: لمس و کشیدن (جوی‌استیک)
- F: روشن/خاموش کردن چراغ‌قوه (برای فردین و دیان)
- E: فلش دیان (stun فرزاد)
- چت: در جعبه‌ی پایین بنویسید و ارسال کنید (۲۰۰ کاراکتر)

## اجرا روی رایانه‌ی شخصی

1. روی `START.bat` دو بار کلیک کنید.
2. آدرس `http://localhost:3000` در مرورگر باز می‌شود.
3. برای بازی با دوستتان، کد ۶ کاراکتری لابی را برای او بفرستید.

یا به‌صورت دستی:

```bash
npm install
npm start        # یا: node server.js
# سپس http://localhost:3000
```

## فایل‌های پروژه

- `server.js` — سرور بازی (اتاق‌ها، نقش‌ها، قوانین برد/باخت)
- `public/index.html` — صفحه‌ی بازی
- `public/style.css` — استایل فارسی تاریک
- `public/net.js` — ارتباط Socket.IO
- `public/horror.js` — موتور بازی (نقشه، شخصیت‌ها، هوش مصنوعی، رندر)
- `public/app.js` — اتصال UI به سرور
- `test-horror.js` — تست‌های یکپارچه‌سازی (run بزنید: `node test-horror.js`)

## انتشار روی اینترنت

برای بازیکنان واقعی از ایران و نقاط مختلف، سرور باید روی یک هاست عمومی با پشتیبانی WebSocket اجرا شود. راهنمای کامل در `DEPLOY.md`.

نکته‌ی مهم درباره‌ی ایران: سرعت اتصال به سرورهای خارجی (از جمله Render) برای کاربران ایرانی ممکن است متغیر و گاهی کند یا قطع‌وصلی داشته باشد. این محدودیت شبکه است و ربطی به خود بازی ندارد.
