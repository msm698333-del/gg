# نقشه مهاجران — بازی آنلاین دوبعدی چندنفره

بازی دو نفره / چندنفره آنلاین با Node.js و Socket.IO.

## نیازها
- Node.js نسخه ۱۸ یا بالاتر (https://nodejs.org)
- یک مرورگر مدرن (Chrome، Edge، Firefox)

## اجرای سریع (ویندوز)

1. فایل‌های پروژه را در یک پوشه قرار دهید.
2. روی `START.bat` دو بار کلیک کنید.
3. سرور روی پورت ۳۰۰۰ اجرا می‌شود و آدرس `http://localhost:3000` را در مرورگر باز کنید.
4. برای بازیکن دیگر، کد ۶ کاراکتری اتاق را به اشتراک بگذارید.

## اجرای دستی (همه سیستم‌عامل‌ها)

```bash
cd پوشه-پروژه
npm install
node server.js
# یا: npm start
```

سپس در مرورگر `http://localhost:3000` را باز کنید.

## کد لابی ۶ کاراکتری

پس از ساخت اتاق، کد ۶ کاراکتری نمایش داده می‌شود. این کد را برای دیگران بفرستید تا با وارد کردن آن به همان اتاق متصل شوند.

## فایل‌های پروژه

- `server.js` — سرور بازی (Express + Socket.IO)
- `public/index.html` — صفحه بازی
- `public/style.css` — استایل مدرن فارسی
- `public/socket-client.js` — ارتباط WebSocket
- `public/game.js` — رندر کانواس و منطق بازی
- `public/app.js` — اتصال UI به سرور
- `START.bat` — راه‌انداز ویندوز
- `DEPLOY.md` — راهنمای انتشار روی اینترنت
- `test-flow.js` — تست یکپارچگی Socket.IO

## اجرای تست‌ها

```bash
npm install
node test-flow.js
```

اگر همه پیام‌ها به شکل `PASS` نمایش داده شوند، همه چیز سالم است.

## حداکثر بازیکن

هر اتاق حداکثر ۱۲ بازیکن دارد. اگر اتاق پر شد، پیام «اتاق پر است» نمایش داده می‌شود.

## ساختار داده روی سرور

- هر اتاق یک کد تصادفی ۶ کاراکتری دارد.
- اتاق ۲ ساعت زنده می‌ماند و اگر خالی شود بلافاصله حذف می‌شود.
- سرور محدودیت ۱۰ پیکسل حرکت در هر tick را اعمال می‌کند.
- پیام‌های چت فقط ۲۰۰ کاراکتر هستند.

## انتشار اینترنتی

پیشنهاد: ابتدا `DEPLOY.md` را بخوانید. خلاصه:
- سرور را روی هاست Node.js با پشتیبانی WebSocket منتشر کنید.
- پس از انتشار، همه می‌توانند با آدرس‌های متفاوت از شهرهای مختلف به بازی متصل شوند.
